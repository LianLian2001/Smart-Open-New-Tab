# Smart Open New Tab

An intelligent userscript that opens normal page navigation in new tabs
while preserving pagination, search, authentication, modal, menu, theme,
download, and other in-page interactions.

## Features

- Smart navigation detection
- Open normal page navigation in new tabs
- Keep pagination in the current tab
- Keep search navigation in the current tab
- Protect login and authentication flows
- Protect modal dialogs and popup interactions
- Protect menus, tabs, accordions and theme toggles
- Protect downloads
- Shadow DOM support
- Per-domain enable/disable
- Per-domain debug mode
- Modifier-click support

- 按域名单独启用 / 禁用脚本
- 按域名开启调试模式
- 支持修饰键（Ctrl/Cmd/ 中键）点击
